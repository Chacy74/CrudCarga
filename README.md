# v1 | CRUD de caminhões
Execute: `cd backend && dotnet run --urls http://localhost:5080` (SDK .NET 10). Endpoints GET/POST `/api/caminhoes`, GET/PUT/DELETE `/api/caminhoes/{id}`. Persistência em `backend/dados.json` (ignorado pelo Git). Exemplo POST: `{"placa":"ABC1D23","modelo":"Truck","capacidadeKg":12000}`.
